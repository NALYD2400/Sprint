Sprint 0.5.8 harmonise les pages Projets, Ports et Logs avec le thème choisi, et gagne de la place pour afficher plus de ports et de lignes de logs.

- **Projets** : terminal, lancement et menu « ... » sur la ligne du projet, colonnes d’actions alignées entre le projet et ses serveurs, sans doublon quand le projet est déplié. Le menu reprend le gabarit du menu contextuel, avec une action destructive en rose. Le bouton Nouveau et « Tout lancer » suivent l’accent et le mode clair/sombre.
- **Ports** : recherche et tri sur la même ligne que les filtres, en-tête resserré, lignes plus compactes et fond visible derrière le tableau.
- **Logs** : en-tête et barre de console resserrés, panneau de logs translucide pour laisser voir le fond.

Validation : 143 contrôles UI avec serveurs simulés, lint et build Windows réussis. Vérification visuelle en thème sombre.

Téléchargements Windows x64 :

- **Sprint_0.5.8_x64-setup.exe** : installateur recommandé, également utilisé par la mise à jour intégrée.
- **Sprint_portable_0.5.8_x64.exe** : exécutable autonome, à lancer sans installation ; nécessite Microsoft Edge WebView2 Runtime sur le poste.
- **SHA256SUMS.txt** : empreintes SHA-256 des deux exécutables.
