## Aperçu web et Logs

- Les onglets de l’aperçu web et des logs se gèrent depuis la barre latérale. Chaque onglet retrouve son serveur et ses réglages quand vous y revenez.
- L’aperçu web et les logs disposent de commandes repliables pour laisser plus de place au contenu. Deux consoles de logs peuvent rester ouvertes en parallèle.

## Interface

- La palette de commandes, les formulaires de projet et les dialogues de confirmation reprennent les couleurs du thème clair ou sombre.
- Un bouton dans le tableau de bord permet d’ajouter le premier projet. Les actions groupées de la page Projets sont identifiées par des icônes.

## Téléchargements Windows x64

- `Sprint_0.5.20_x64-setup.exe` est l’installateur utilisé par la mise à jour intégrée.
- `Sprint_portable_0.5.20_x64.exe` se lance sans installation de Sprint et utilise Microsoft Edge WebView2 Runtime.
- `SHA256SUMS.txt` contient les empreintes SHA-256 des deux exécutables.
