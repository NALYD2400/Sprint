Sprint 0.5.11 harmonise les fonds de l’interface et simplifie les paramètres.

- Le tableau des ports reprend le fond de la page, y compris dans l’en-tête fixe. Les lignes défilantes ne recouvrent plus les titres.
- La recherche Ctrl+K utilise le fond animé et les réglages de couleur, d’intensité, de flou et de vitesse de l’application.
- La sélection accidentelle du texte est désactivée dans l’interface. Elle reste disponible dans les logs et les champs de saisie.
- Les paramètres passent de sept à six sections : les outils pour assistants IA sont regroupés dans À propos et les options des logs sont repliées par défaut.
- Suppression de code et de styles inutilisés, regroupement des valeurs par défaut et de la comparaison des versions, retrait de traitements redondants au démarrage.
- Les liens GitHub et la recherche de mises à jour utilisent désormais le dépôt Sprint.

Téléchargements Windows x64 :

- **Sprint_0.5.11_x64-setup.exe** : installateur et mise à jour intégrée.
- **Sprint_portable_0.5.11_x64.exe** : exécutable autonome, nécessite Microsoft Edge WebView2 Runtime.
- **SHA256SUMS.txt** : empreintes SHA-256 des deux exécutables.

Validation automatisée : 149 contrôles UI, 48 contrôles des parcours serveur, tests du tableau de bord, 22 tests Rust, lint, compilation et Clippy strict. Les tests UI simulent les commandes IPC ; ils ne déclenchent pas les intégrations système personnelles.
