Sprint 0.5.12 corrige l’écran noir au lancement après la mise à jour 0.5.11.

- Régénération de la ressource HTML compressée corrompue dans le cache de compilation, responsable du message `asset not found: index.html`.
- La construction de l’installateur vérifie désormais la lecture effective de toutes les ressources intégrées au contexte de production : page HTML, JavaScript et CSS. Un cache illisible bloque la publication du paquet.
- Les changements du dossier `dist` sont suivis par la compilation native.

Téléchargements Windows x64 :

- **Sprint_0.5.12_x64-setup.exe** : installateur et réparation de la version installée, en conservant les projets et les paramètres.
- **Sprint_portable_0.5.12_x64.exe** : exécutable autonome, nécessite Microsoft Edge WebView2 Runtime.
- **SHA256SUMS.txt** : empreintes SHA-256 des deux exécutables.

Si Sprint reste bloqué sur l’écran noir, exécutez directement l’installateur 0.5.12 ; l’interface 0.5.11 ne permet pas d’ouvrir la mise à jour intégrée.

Validation : panne reproduite avec le cache HTML corrompu ; test des ressources intégrées réussi après régénération ; 23 tests Rust et lint réussis ; compilation de l’installateur NSIS.
