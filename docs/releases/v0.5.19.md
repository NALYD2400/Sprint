Les sept rubriques des paramètres tiennent chacune sur une ligne. Chaque icône accompagne son libellé et la description apparaît dans la rubrique ouverte.

Le bouton soleil ou lune en haut à droite permet de changer de thème. Dans Apparence, l’option « Selon Windows » permet de suivre la préférence système pour les animations.

À partir de cette version, la fenêtre de mise à jour affiche le texte en gras et les listes à puces des notes de version.

Pour Windows x64, choisissez l’installateur ou l’exécutable portable. Le fichier SHA256SUMS.txt contient leurs empreintes de vérification.
