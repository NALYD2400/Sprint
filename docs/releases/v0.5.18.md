Sprint 0.5.18 accélère l’affichage et simplifie les écrans les plus utilisés.

- **Interface** — Les fenêtres secondaires se chargent à l’ouverture. Les polices Geist sont embarquées et l’option système de réduction des animations est prise en compte.
- **Projets** — Le formulaire d’ajout conserve le dossier et les champs saisis quand on le ferme avant l’enregistrement. La durée de fonctionnement reste visible après un changement de page.
- **Aperçu et logs** — L’aperçu s’ajuste dès le premier affichage. Les contrôles des logs et les formulaires de projet ont été simplifiés.
- **Performances** — Les graphiques recalculent moins de données au survol. La collecte des métriques se déroule en arrière-plan et le menu Windows met en cache les icônes des projets.

Téléchargements pour Windows x64

- `Sprint_0.5.18_x64-setup.exe` pour installer ou mettre à jour Sprint.
- `Sprint_portable_0.5.18_x64.exe` pour lancer la version portable.
- `SHA256SUMS.txt` pour vérifier les deux exécutables.
