Sprint 0.5.15 permet de brancher Sprint dans Claude Code, Cursor ou Codex, et ajoute des menus contextuels sur les projets.

- Serveur MCP local pour connecter un dossier sans éditer `projects.json` à la main. La commande et le port sont lus dans le projet, et un dossier déjà branché n’est pas dupliqué.
- Réglages, section À propos : « Connecter une IA » copie la commande pour Claude Code, Cursor ou Codex. L’installateur place `mcp/server.mjs` à côté de l’application.
- Clic droit sur un projet ou un serveur : actions du projet (démarrer, ouvrir, supprimer). Le menu du navigateur reste disponible dans les champs et les dialogues.

Téléchargements Windows x64 : installateur, version portable et empreintes SHA-256.
